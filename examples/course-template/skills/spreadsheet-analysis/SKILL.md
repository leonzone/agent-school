# 表格分析

## 必要输入

- 获取表格文件或数据内容，确认需要分析的工作表和字段。
- 确认业务问题、统计口径、时间范围和期望输出。
- 确认表头、单位、币种、时区以及空值和重复值的含义。
- 无法读取文件或字段含义不明时先说明并请求补充，不自行猜测。

## 执行流程

1. 检查工作表范围、字段类型、行列数量及合并单元格情况。
2. 识别空值、重复记录、异常格式、极端值和口径不一致。
3. 保留原始数据，明确记录采用的清洗规则和排除范围。
4. 根据问题选择汇总、分组、趋势、占比或交叉对比方法。
5. 核对计算范围与分母，避免把文本数字或隐藏行误算进去。
6. 对关键结果进行抽样复算，并检查总量与分组之和是否一致。
7. 解释变化的幅度、方向和可能原因，区分相关性与因果性。
8. 汇总数据限制、异常记录和需要业务方确认的问题。

## 输出结构

1. **分析范围**：数据来源、工作表、时间范围和统计口径。
2. **数据质量**：缺失、重复、异常及已采取的处理方式。
3. **核心结果**：用表格列出指标、分组、数值和单位。
4. **主要发现**：按重要性解释结果、对比和趋势。
5. **限制与建议**：列出不可推断事项和后续核查步骤。

## 边界

- 不修改或覆盖原始表格，除非用户明确要求并提供新位置。
- 不编造缺失数据，不静默删除异常行或改变统计口径。
- 不把相关关系描述为因果关系，不作无数据支持的预测。
- 无法执行公式或读取特定格式时，明确说明实际完成的范围。

## 交付检查

1. 核对指标公式、单位、筛选条件和关键汇总结果。
2. 检查输出是否同时呈现数据质量问题和分析限制。
3. 确保结论可由表格数据复核，建议与发现一一对应。
