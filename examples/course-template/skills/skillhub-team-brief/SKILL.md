# 团队简报整理

1. 阅读用户提供的全部测试材料，提取材料中明确出现的事实、数据、负责人和时间。
2. 阅读本 Skill 的 `references/template.md`，严格采用其中的标题和顺序。
3. 在当前工作目录根目录创建 `team-brief.md`，使用简体中文和 Markdown 格式。
4. 只整理材料支持的信息，不编造进展、数据或结论。缺少的信息写“待确认”，相近事项应合并，重复信息只保留一次。
5. 下一步行动应尽量包含负责人和时间；材料未提供时在对应位置写“待确认”。
6. 完成后检查文件确实存在，并在最终回复中给出文件路径和不超过三句话的内容摘要。
