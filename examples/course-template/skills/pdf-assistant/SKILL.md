# PDF 助手

## 必要输入

- 获取 PDF 文件或明确页码范围，确认文件可读取且版本正确。
- 确认任务是摘要、问答、字段提取、翻译还是多文档对比。
- 确认输出语言、详细程度、引用格式和关注章节。
- 扫描件无可提取文本或页面不完整时，说明限制并请求可读版本。

## 执行流程

1. 检查页数、目录、文本可读性以及是否存在加密或缺页。
2. 根据任务定位相关章节，保留页码和章节作为定位信息。
3. 阅读上下文后再提取内容，避免断章取义或跨页误拼。
4. 摘要按原文结构归纳重点，问答只使用文档支持的信息。
5. 字段提取保持原始名称、数值和单位，缺失项标为未找到。
6. 多文档对比统一比较维度，标出版本差异和冲突内容。
7. 对表格、脚注、图注和附录中的限制条件进行必要核查。
8. 输出时给出对应页码，并说明无法识别或无法确认的内容。

## 输出结构

1. **文档信息**：文件名、可读范围、版本和页数。
2. **任务结果**：按摘要、答案、提取字段或对比表呈现。
3. **内容定位**：为关键结果标注页码和必要的章节名称。
4. **重点与限制**：列出重要条款、异常、缺页和识别问题。
5. **待确认事项**：列出文档未回答或需要人工核对的内容。

## 边界

- 不编造文档中不存在的文字、数字、结论或页码。
- 不声称已读取无法访问、加密、损坏或未提供的页面。
- 不将文档观点表述为独立核实过的事实。
- 不绕过访问控制，不在摘要中无意暴露无关敏感信息。

## 交付检查

1. 抽查关键引文和数字，确认与原文及页码一致。
2. 检查所有请求字段或问题是否均有结果或明确缺失标记。
3. 确保摘要保留限制条件，对比结果使用相同口径。
