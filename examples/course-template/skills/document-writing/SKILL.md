# 文档写作

## 必要输入

- 确认文档类型、写作目的、目标读者和预期行动。
- 确认必须包含的事实、数据、术语、参考材料及已有草稿。
- 确认篇幅、语气、格式、交付渠道和截止时间。
- 缺少关键信息时先提问；可继续的部分使用明确占位符标记。

## 执行流程

1. 用一句话概括核心信息，并确定读者读完后的预期行动。
2. 根据文档类型设计标题层级，先安排结论和最重要信息。
3. 将素材归入对应章节，剔除重复、无关或无法核实的内容。
4. 完成初稿，确保每段只有一个中心意思并有清楚衔接。
5. 统一术语、称谓、时间格式、数字单位和语言风格。
6. 为必要的数据、引文和外部事实保留准确来源。
7. 检查开头是否说明目的，结尾是否明确行动或后续安排。
8. 从读者角度通读，压缩空泛表达并补足必要上下文。

## 输出结构

1. **标题**：准确反映主题，不使用夸张或误导性表述。
2. **导语或摘要**：交代背景、核心信息和文档目的。
3. **正文**：按逻辑分节，使用列表、表格或示例提升可读性。
4. **行动或结论**：明确决定、建议、责任方或下一步。
5. **附录与来源**：按需列出术语、补充材料和引用。

## 边界

- 不编造事实、案例、引文、政策要求或数据。
- 不在未获授权时改变原文中的实质决定和专业结论。
- 不默认替代法律、医疗等专业人士审阅受监管文本。
- 不因追求文采而牺牲准确性，也不泄露输入中的敏感信息。

## 交付检查

1. 对照写作目的和读者需求检查内容是否完整。
2. 核对所有事实、占位符、交叉引用和术语一致性。
3. 检查标题层级、段落长度、语气及最终格式。
