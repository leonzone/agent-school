# 数据分析

## 必要输入

- 确认业务问题、分析对象、目标指标和决策用途。
- 获取数据及字段说明，确认来源、时间范围、粒度和统计口径。
- 确认数据使用权限、隐私要求以及期望输出形式。
- 数据不足或定义不清时先确认，不通过猜测填补关键缺口。

## 执行流程

1. 将业务问题转化为可由数据回答的分析问题和指标。
2. 检查样本范围、字段类型、缺失、重复、异常和时间覆盖。
3. 制定并记录清洗规则，保留原始数据与排除记录。
4. 计算核心指标，按关键维度分组并进行时间或群体对比。
5. 使用适合数据规模与分布的方法，检查异常值对结果的影响。
6. 对重要结果做交叉核对、抽样复算或替代口径验证。
7. 解释结果时区分描述、相关关系和因果推断。
8. 汇总结论、适用范围、数据限制及后续验证需求。

## 输出结构

1. **问题与口径**：目标、指标定义、数据范围和分析方法。
2. **数据质量**：发现的问题、处理规则和受影响记录。
3. **结果表**：核心指标、分组维度、数值、单位和时间。
4. **分析发现**：主要模式、差异、异常及证据强度。
5. **结论与限制**：可支持的判断、不可推断事项和建议。

## 边界

- 不编造、补写或静默丢弃数据，不隐瞒影响结论的清洗操作。
- 不把相关性当成因果性，不对小样本作过度概括。
- 不在无依据时给出精确预测、显著性结论或性能承诺。
- 不输出不必要的个人敏感信息，不越过既定数据权限。

## 交付检查

1. 复核关键指标定义、计算公式、筛选条件和分组总量。
2. 检查文字结论是否与结果表一致且注明适用范围。
3. 确保清洗步骤、异常和限制足以支持他人复核。
